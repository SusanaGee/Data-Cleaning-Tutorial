# 🧼 Data-Cleaning-Tutorial

¡Bienvenid@ a este recorrido por el fascinante mundo de la limpieza de datos! 🚀  
En este proyecto aprenderás paso a paso cómo preparar una base de datos para análisis profesional, desde lo más básico hasta técnicas un poco más avanzadas.  
La limpieza de datos no solo mejora la calidad de la información, ¡sino que también hace que los insights cobren vida! ✨

---

## 📚 ¿Qué aprenderás aquí?

🔸 **Renombrar columnas** para mejorar la legibilidad del código.  
🔸 **Imputar valores faltantes** usando estrategias según el tipo de variable.  
🔸 **Detectar y tratar outliers** mediante gráficos tipo boxplot.  
🔸 **Estandarizar y normalizar** variables numéricas.  
🔸 **Enriquecer tu dataset** con nuevas columnas útiles para el análisis.  
🔸 Aplicar todo lo anterior para lograr una **base de datos limpia, coherente y lista para modelos**.
